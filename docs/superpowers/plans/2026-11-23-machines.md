# Materials 7c — magnetizer, etcher, extruder and molds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the three remaining machines (magnetizer, etcher, extruder with its mold slot), the four molds and the eight machine products, with their machine and crafting recipes, textures and screens (PR 7c, branch `feat/machines`, stacked on `feat/machine-core`).

**Architecture:** 7b built one generic machine: `MachineKind` describes a machine (recipe type, serializer, book category, number of inputs, `needsMold`), `MachineRecipe` already parses and checks an optional `mold`, and `MachineBlockEntity` / `MachineMenu` / `MachineScreen` adapt to `kind()`. 7c adds three kinds and their blocks, then one new slot, `MOLD`, used only when `kind().needsMold()`: hoppers never reach it, the recipe input reads it, the menu shows it only on the extruder, and the recipe placer fills it (or ghosts it). The client effects (sound, particles) move from `CoilWinderBlock` into `MachineBlock`, so each machine only declares its own.

**Tech Stack:** Fabric (Minecraft 26.3, Mojang names), Fabric API, `fabric-data-generation-api-v1`, GameTest, JUnit 5, Pillow texture generator.

**Spec:** [docs/superpowers/specs/2026-11-22-materials-design.md](../specs/2026-11-22-materials-design.md) (sections 1 "Découpage" 7c, 2 D3–D4, 3, 5, 6.1 machines and molds, 6.2, 6.4, 7, 8, 9).

## Global Constraints

- Mojang names only; verify every class before use (`minecraft-dev` MCP or the sources in `.gradle/loom-cache/minecraftMaven/…/26.3/*-sources.jar`). No `net.minecraft.client` import in `src/main/java`. Every block/item gets its id before construction (`properties.setId(key)`).
- Code rules: Javadoc on every class, public/protected method and method over 10 lines (`@param`/`@return` on public ones); cognitive complexity ≤ 15, cyclomatic ≤ 10, at most two nested `if`/loops; named constants; `RaveCraft.id(path)`; `RaveCraft.LOGGER`.
- Performance: an idle machine does no work per tick; the recipe lookup runs only after an inventory change (the 7b `dirty` flag; the mold slot goes through `setItem`/`setChanged` like the others).
- Kinds (spec 5.1, 5.3): `magnetizing` / `magnetizer` / 2 inputs / no mold; `etching` / `etcher` / 3 inputs / no mold; `extruding` / `extruder` / 1 input / mold required. 100 ticks per operation, 1 energy unit per operation.
- Machine recipes (spec 5.2), ids `<result>_from_<process>`:
  - magnetizing: 1 iron ingot + 1 redstone dust → 1 `iron_magnet`; 1 `neodymium_ingot` + 1 iron ingot → 2 `neodymium_magnet`;
  - etching: 1 `circuit_board` + 2 `copper_wire` + 1 redstone dust → 1 `simple_circuit`; 1 `silicon_wafer` + 2 gold nuggets + 1 redstone dust → 1 `chip`;
  - extruding: 1 `bitumen` + `sheet_mold` → 2 `plastic_sheet`; 3 `bitumen` + `casing_mold` → 1 `plastic_casing`; 2 `bitumen` + `membrane_mold` → 1 `reinforced_membrane`; 1 `bitumen` + `board_mold` → 2 `circuit_board`.
- Crafting (spec 6.1; `I` iron ingot, `R` redstone dust): `magnetizer` `IRI / RIR / IRI`; `etcher` `IGI / RAR / III` (`G` glass, `A` amethyst shard); `extruder` `IPI / IFI / III` (`P` piston, `F` furnace); molds `III / IXI` with `X` = heavy weighted pressure plate (`sheet_mold`), bucket (`casing_mold`), bowl (`membrane_mold`), redstone dust (`board_mold`). Unlock: one `has_<item>` criterion per distinct ingredient, OR-ed (6.2).
- Names (fr / en): `magnetizer` Magnétiseur / Magnetizer; `etcher` Graveur / Etcher; `extruder` Extrudeuse / Extruder; `iron_magnet` Aimant en fer / Iron Magnet; `neodymium_magnet` Aimant en néodyme / Neodymium Magnet; `plastic_sheet` Plaque de plastique / Plastic Sheet; `plastic_casing` Boîtier en plastique / Plastic Casing; `circuit_board` Support de circuit / Circuit Board; `simple_circuit` Circuit simple / Simple Circuit; `chip` Puce / Chip; `reinforced_membrane` Membrane renforcée / Reinforced Membrane; `sheet_mold` Moule à plaque / Sheet Mold; `casing_mold` Moule à boîtier / Casing Mold; `membrane_mold` Moule à membrane / Membrane Mold; `board_mold` Moule à support / Board Mold. Rulings (spec is silent):
- **Mold slot:** one block entity for every machine; slot `MOLD = 5`, `SIZE = 6`. Old saves (5 slots) load unchanged. On machines without a mold the slot exists but is inactive and refuses everything.
- **Molds are tools:** stack size 1, item tag `ravecraft:molds` (the mold slot accepts only that tag), never consumed.
- **Effects:** `MachineBlock` implements `animateTick` once from a `MachineEffects(SoundEvent sound, float pitch, ParticleOptions particle)` returned by each subclass; the coil winder keeps its current crafter sound and electric spark. Candidates for the new machines are shown in Task 1.

## Review Focus

1. Changing the mold during an operation switches the recipe: progress goes back to zero, and nothing is produced with the old mold's result — pinned in Task 3 (`changingMoldResets`).
2. Shift-clicking a mold from the inventory on the extruder fills the mold slot, never an input; on another machine it goes nowhere special (inputs refuse it unless a recipe uses it) — pinned in Task 4 (`shiftClickMoldGoesToMoldSlot`).
3. Clicking an extruder recipe while another mold sits in the slot returns that mold to the player and places the right one; without the mold in the inventory, the mold shows as a ghost — pinned in Task 4 (`placementSwapsMold`, `placementGhostsMissingMold`).
4. A hopper on any face never inserts into or pulls from the mold slot, even with a mold in its inventory — pinned in Task 3 (`hoppersIgnoreMold`).
5. Two ingredients of the same item on the etcher (redstone as ingredient while redstone also fuels the machine): shift-clicked redstone goes to energy first, and an etching recipe still finds its redstone in an input — pinned in Task 3 (`etchingUsesInputRedstoneNotEnergy`).
